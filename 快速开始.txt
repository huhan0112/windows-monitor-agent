================================================================================
  Windows 服务器监控系统 - 快速开始指南
================================================================================

📦 部署步骤（3 步完成）

第一步：上传到服务器
------------------------
将整个 windows-monitor-deployment 文件夹上传到服务器任意位置


第二步：配置邮箱通知（重要！）
------------------------
1. 打开 config\smtp.conf
2. 修改以下内容：

   SMTP_USERNAME=你的QQ号@qq.com
   SMTP_AUTH_CODE=你的QQ邮箱授权码（16位）
   FROM_ADDRESS=你的QQ号@qq.com
   TO_ADDRESS=接收告警的邮箱

💡 如何获取 QQ 邮箱授权码？
   1. 登录 QQ 邮箱网页版
   2. 设置 → 账户 → 开启 IMAP/SMTP 服务
   3. 生成授权码（16 位字符，类似：abcd efgh ijkl mnop）


第三步：运行安装
------------------------
右键 PowerShell → 以管理员身份运行，执行：

   cd 你的上传路径\windows-monitor-deployment
   .\install.ps1

安装脚本会自动：
  ✓ 安装 windows_exporter 和 Prometheus 服务
  ✓ 配置监控规则和告警
  ✓ 启动所有服务
  ✓ 创建崩溃监控计划任务


================================================================================
  安装完成后
================================================================================

🌐 访问监控界面
   浏览器打开：http://服务器IP:9090

📊 监控项目
   - CPU 使用率（持续 > 85% 告警，> 95% 严重告警）
   - 内存使用率（> 90% 告警，> 95% 严重告警）
   - 磁盘空间（剩余 < 10% 告警）
   - 系统崩溃检测（自动邮件通知）

📧 告警通知
   当触发告警时，会自动发送邮件到你配置的邮箱


================================================================================
  常用命令
================================================================================

查看服务状态
   Get-Service windows_exporter
   Get-ScheduledTask -TaskName "WindowsMonitor-Prometheus", "WindowsMonitor-CrashWatchdog" | Select-Object TaskName, State

重启 Prometheus（计划任务，用 Stop + Start）
   Stop-ScheduledTask -TaskName "WindowsMonitor-Prometheus"
   Start-ScheduledTask -TaskName "WindowsMonitor-Prometheus"

查看日志
   Get-Content C:\monitoring\logs\watchdog.log -Tail 50

手动测试邮件
   cd C:\monitoring\scripts
   .\Send-QQMail.ps1 -Subject "测试" -Body "测试邮件" -ToAddress "你的邮箱"
